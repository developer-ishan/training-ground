🔥 1. Resume Reviewer / ATS Optimizer (Must-have)

What it does

Rewrites bullets with impact
Adds metrics (%, $, scale)
Optimizes for ATS keywords

How to use in Claude
Create a reusable prompt like:

“Act as a senior recruiter. Rewrite my resume bullets using strong action verbs, quantify impact, and optimize for ATS systems.”

Why it’s powerful

Mimics tools like Jobscan
Instantly upgrades weak bullets → strong impact statements
⚡ 2. STAR Bullet Generator Skill

What it does

Converts your work into Situation–Task–Action–Result
Perfect for tech + product roles

Prompt idea

“Convert this experience into STAR format resume bullets with measurable outcomes.”

🧠 3. Impact Amplifier (Underrated but powerful)

What it does

Turns normal work into high-impact achievements

Example:

❌ “Worked on pricing service APIs”
✅ “Designed and scaled pricing APIs handling X requests/day, improving latency by Y%”

Prompt:

“Rewrite this to sound like high-impact, senior-level work.”

🎯 4. Job Description Matcher

What it does

Tailors resume per job description
Highlights missing keywords

Workflow
Paste:

Your resume
Job description

Ask:

“Match my resume to this JD and suggest improvements to increase relevance.”
